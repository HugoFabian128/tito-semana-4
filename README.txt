===================================================
PROYECTO TITO: ASISTENTE ESCOLAR INTELIGENTE POR VOZ
Curso: Procesamiento de Lenguaje Natural
Semana 4 · Corpus y datos lingüísticos
===================================================

1. DESCRIPCIÓN DEL PROYECTO
Este proyecto contiene el primer dataset etiquetado para entrenar 
a "Tito", un asistente escolar por voz diseñado para responder 
dudas de estudiantes de preparatoria.

2. ESTRUCTURA DEL DATASET (dataset_tito.csv)
- Total de registros: 120 preguntas.
- Columnas: 
    * texto: Pregunta realizada por el estudiante.
    * categoria: Intención escolar asignada (8 categorías en total).
- Codificación: UTF-8 (para preservar acentos, ñ y signos del español).

3. FUENTES DE INFORMACIÓN
- Reglamento escolar y sitio web institucional.
- Preguntas frecuentes recopiladas en trámites escolares reales.
- Frases generadas en clase para aumentar la variedad lingüística.

4. NOTA SOBRE PRIVACIDAD DE DATOS
Este dataset contiene únicamente preguntas generales e hipotéticas. 
NO almacena nombres de alumnos, matrículas, números telefónicos ni 
ningún otro dato personal sensible.
